# MineVision Analytics

Plataforma de Analítica Avanzada para Operaciones Mineras desarrollada con Python, Dash Plotly y Microsoft Azure.

## Objetivo

Construir una plataforma capaz de procesar, almacenar y visualizar información operacional proveniente de una operación minera utilizando servicios de Microsoft Azure.

## Tecnologías

- Python
- Dash
- Plotly
- FastAPI
- Pandas
- Azure Data Lake Storage
- Azure Cosmos DB
- Azure App Service
